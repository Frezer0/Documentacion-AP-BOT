# 🛡️ Registro Albion

Este módulo se encarga de gestionar cómo los usuarios ligan sus cuentas de Discord con sus personajes del juego, y de mapear los rangos internos.

## ⚙️ Configuración del Módulo
Para acceder, usa `/config_servidor` y selecciona **Registro Albion** en el menú. 

### Opciones y Campos:
1. **Configurar Panel de Registro:**
   * Genera el botón público en un canal para que tus miembros hagan clic y verifiquen sus cuentas usando la API de Albion.
2. **Asignación de Roles Base:**
   * **Rol de Jugador (Miembro):** El rol que se otorga cuando un usuario verificado pertenece a tu gremio principal.
   * **Rol de Aliado:** El rol que se otorga si el jugador verificado pertenece a la Alianza pero no a tu gremio directamente.
3. **Pactos de No Agresión (NAPs):**
   * Puedes registrar Nombres de Gremios o Alianzas con las que tienes NAP para que el bot los etiquete como amistosos en otros módulos (como la Killboard).
