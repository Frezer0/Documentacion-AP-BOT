

# AP BOT - Documentación Oficial

Bienvenido al centro de ayuda de **Ap BOT v3**. Todo el ecosistema de este bot ha sido diseñado para ser controlado desde un único menú maestro interactivo.

## 🎛️ El Comando Principal: `/config_servidor`

Para acceder a cualquier configuración, un administrador debe ejecutar el comando `/config_servidor` en tu servidor de Discord. Esto desplegará un panel con un menú desplegable (Dropdown) con 8 módulos exactos.

A continuación, haz clic en el módulo sobre el que necesitas ayuda para ver sus detalles y campos configurables:
