# 🎮 Partys y Eventos

Las Llamadas a las Armas (CTAs), Ganking y grupos de Fama se controlan desde este módulo.

## ⚙️ Configuración del Módulo
Para acceder, usa `/config_servidor` y selecciona **Partys y Eventos** en el menú.

### Opciones y Campos:
1. **Canal Principal de CTAs:**
   * El canal público donde aparecerán los carteles interactivos de reclutamiento.
2. **Asignación de Roles de Composición:**
   * **Rol Tanque:** Identificador visual de Discord para los que hagan clic en el escudo.
   * **Rol Healer:** Identificador visual para curanderos.
   * **Rol DPS:** Identificador visual para daño.
   * **Rol Support:** Identificador visual para soporte.
3. **Limpieza Automática (Purga):**
   * Configura después de cuántos días el bot debe borrar de la base de datos las Parties que ya terminaron o expiraron por falta de actividad.
